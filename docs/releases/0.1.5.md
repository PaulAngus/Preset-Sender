# Preset Sender 0.1.5

This release brings the latest Sender source and its distributed artifacts under
one version. It includes the application-name update and the existing bank-aware
1024-preset sender, feedback protection and route cleanup behavior.

The exact MIDI dependency family is 0.3.14, built from clean committed latest
MIDIHelperLibrary source. This includes the existing UMP/SysEx batching, decoder
reset and Apple mixed-writer RTP changes. The four package files, source manifest
and normal-publication receipt are pinned in `dependencies/midi`.

The normal Windows publisher retains its self-contained compressed single EXE,
bundled native dependencies and ordinary startup. It now requires clean source,
uses fresh short intermediates and records source/binary/archive hashes. Older
0.1.4 receipts and artifacts remain historical identities, not 0.1.5 evidence.

No tests or application launches are authorized for this publication. No prior
component, native or hardware results are transferred to this version. Functional
acceptance remains incomplete under the separate shared-MIDI platform workstream.
