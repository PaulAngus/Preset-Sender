# Preset Sender 0.1.4

Initial source release: 19 October 2026. Local release updated: 21 October 2026.

## Local update — 21 October 2026

- Support **1024 presets**: 0–1023 with zero-based numbering, or 1–1024 with one-based numbering. Set **Digits to 4** for four-digit entry.
- Select the requested bank with CC#0 before every Program Change, so the receiver's starting bank cannot change the requested selection. Show the selected bank and actual wire PC in Last sent.
- Make Next/Prev cross bank boundaries and wrap across the supported range; Last remembers the previous absolute preset across banks. Preserve pending entry after failed sends and resolve the selected output against the current port catalog when connecting.
- Disconnect rapid MIDI feedback loops and release forwarded held notes and owned sustain (CC64) when their route stops.

### Validation

- **194 functional checks passed**, including all 1024 presets against an independent simulated receiver, both numbering settings, different starting banks, individual/all-channel output, bank-boundary navigation, four-digit keyboard/MIDI auto-send, and failed-send retention.
- **Three native MIDI checks passed** against the standalone published Windows EXE. The macOS target cross-build and changed-source whitespace verification also passed; native Mac execution remains a separate qualification.
- **24 physical FM9 selection/navigation checks passed** through MIDI Forwarder, using FM9 firmware **12.00** on channel **1**. Independent, checksummed SysEx readback verified the actual selected preset and scene.

### Addressing and receiver limits

The current bank scheme uses CC#0 followed by PC 0–127. Devices requiring CC#32, both bank controllers, or manufacturer-specific SysEx need additional support. Numbering changes labels, not the bank scheme. Receivers must support the selected bank and preset; the FM9 itself has 512 presets.
