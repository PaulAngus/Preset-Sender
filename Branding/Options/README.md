# Preset Sender logo options

Six original raster concept marks. The user originally selected **option 1, DIN Send**, then reassigned it to MIDI Forwarder on 14 October 2026. Preset Sender now uses **Amber Gradient**, selected from [the pedal gradient revisions](../NewOptions/PedalGradients/README.md). These six earlier concepts are retained as references; they are not the current app/website production assets.

1. **DIN Send** — socket with a sending arrow; compact option for the executable icon.
2. **Preset Stack** — preset cards and a MIDI socket.
3. **Cable Send** — a MIDI socket and cable ending in an arrow.
4. **Program Route** — three entry cells routed to a MIDI socket; suits a website lockup.
5. **DIN Arrow** — socket and arrow combined into one silhouette.
6. **Preset Dial** — socket inside a selection arc with an outward arrow.

All six use cobalt blue and deep navy to suit the existing app. Five pin holes are retained as the DIN connector cue. These are design concepts; the chosen artwork still needs final small-size icon adaptation and packaging.

## Primary sources consulted

- [MIDI Association: 5-pin DIN electrical specification](https://midi.org/5-pin-din-electrical-specs) documents the classic MIDI transport connector.
- [MIDI Association: TRS adapter specification](https://midi.org/specification-for-trs-adapters-adopted-and-released) documents smaller tip-ring-sleeve MIDI connections. DIN was chosen as the more explicit connector metaphor for these options; the software itself supports the available MIDI transports.
- [Microsoft Windows app icon design](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-design) recommends simple metaphors, distinctive silhouettes, and legibility at small sizes.
- [Fluent 2 iconography](https://fluent2.microsoft.design/iconography/) informs familiar and legible icon treatment.

The logo is original Preset Sender branding, not the MIDI Association's logo. The blue/navy palette and send-arrow combination are product choices. The generated artwork has a slight tonal treatment despite the flat-colour prompt; final simplification will follow the user's choice.

The complete prompt for each option is in [prompts.md](prompts.md). Each PNG is 1254 × 1254 with transparency. Original imagegen output has been retained in the Codex generated-images folder as well as copied here.
